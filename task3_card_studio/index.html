04 내 템플릿

이미지·문구·비율·색상·위치를 함께 저장합니다. 이 브라우저에만 저장되며 다른 기기와 자동 동기화되지 않습니다.

저장된 템플릿 0개

이름을 입력하고 ‘새 템플릿 저장’을 누르세요.

저장 전에 이미지 데이터를 축소·재인코딩합니다. 브라우저 저장 공간이 부족하면 기존 목록을 지우지 않고 오류를 알려줍니다. 최대 30개.

05 템플릿 백업 · 복원

템플릿 목록 전체를 JSON으로 백업하고 다른 브라우저에서 복원할 수 있습니다. JSON에는 템플릿에 저장된 배경 이미지도 포함됩니다.

JSON 복원 시 파일 전체를 검사한 뒤 저장하며, 실패하면 기존 목록을 유지합니다.

복원에 성공하면 현재 저장된 템플릿 목록을 대체합니다. 유효하지 않은 파일은 기존 편집·템플릿에 영향을 주지 않습니다. 개인 정보가 포함된 이미지·문구의 JSON은 공개로 공유하지 마세요.

긴 문구는 이미지 크기에 맞춰 자동 조정합니다. 모두 표시할 수 없는 경우 원문을 보존하고 경고합니다.
