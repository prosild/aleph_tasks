# ALEPH 과제 5 공통 지침

## 1. 과제 5는 무엇을 하는 과제인가
과제 5는 기능을 많이 만드는 과제가 아니다.
핵심은 작은 개선 하나를 정하고, AI A가 먼저 작업하다가 중간에 멈춘 뒤, AI B가 이전 대화 없이 저장소와 인수인계 문서만으로 이어서 완성할 수 있는지 확인하는 과제다.

즉, 중요한 것은 AI의 기억이 아니라 다음 두 가지다.
1) 저장소에 작업 상태가 잘 남아 있는가
2) 인수인계 문서만으로 새 AI가 같은 검사를 다시 실행할 수 있는가

8) AI A와 AI B가 같은 시작점에서 출발하도록 볼 GitHub 주소

## 10. 카드 2: AI A 중간 작업 기록

### 카드 2의 목적
AI A가 색온도 기능의 일부를 구현한 시점에서 멈춘 뒤, 작업 상태를 AI B에게 넘길 수 있게 한다. AI B가 받을 정보는 저장소와 이 문서뿐이다.

### 실제 폴더 위치
기존 `task3_card_studio`는 읽기 전용 시작 소스다. 구현 파일은 반드시 새 `task5_handoff/index.html`에 작성한다. 이후 프로젝트의 기록 파일은 `task5_handoff/TASK5.md` 하나에 누적한다.

### AI A 시작 기록
- AI A: 이 ChatGPT 세션
- 사용자 시작 지시: 2026-10-23 KST, '자 그럼 진행하자'
- 시작 원본 고정 Git 커밋: `8966689219a8e2c404f4df639e368e4c60b639c5`
- 시작 원본 HTML Git blob ID: `9dc717f228478bed67989dc7ca7990ad5545e2d7`
- 공통 사용 상한: 활동시간 25분 / 사용자 요청 6회 / 도구 호출 30회
- 작업 시작 시각: 2026-10-23 16:11 KST (기록 시각은 분 단위)

### AI A 구현 범위
1) 색온도 조절 슬라이더 추가 (-100에서 +100, 기본값 0)
2) 배경 레이어의 빨간색/파란색 채널을 조절하는 비파괴 색온도 보정
3) 슬라이더 변경 시 미리보기 재렌더링
4) 기존 PNG 다운로드는 같은 캔버스 결과를 사용하므로 보정된 이미지가 내보내기에 반영되도록 연결

색온도 보정 규칙 (AI B는 고정 검사와 이 구현을 참고):
- `delta = round(0.8 * temperature)`
- `R' = clamp(R + delta, 0, 255)`
- `G' = G`
- `B' = clamp(B - delta, 0, 255)`
- 모든 픽셀은 원본을 새로 그린 다음 1회 보정. 반복 누적 금지
- 텍스트는 배경 보정 **이후** 그린다.

### AI A 중단할 범위
- `snapshotTemplate()`, `validTemplate()`, `loadTemplate()`의 색온도 필드 연동은 **아직 구현하지 않음**.
- 템플릿 JSON 백업/복원에서 색온도 값의 영속성은 **아직 구현하지 않음**.
- AI B는 이 부분만 이어서 구현하고 기존 기능을 유지할 것.

### 파일 생성 및 검증 상태
- 본 세션에서는 기존 GitHub 파일을 직접 다운로드하는 네트워크 접근이 실패하였음. 그래서 A 작업은 **고정 원본을 검증해 복사하고 수정하는 재현 스크립트**로 전달함.
- 스크립트: `build_task5_a.py` (작업 시작 전에만 실행, 최종 저장소에는 포함할 필요 없음)
- 실행 명령: `python build_task5_a.py`
- 이 명령은 원본이 로컬에 있으면 원본 Git blob 해시를 검증하여 사용하며, 없으면 위 고정 GitHub 원본 URL에서 내려받음.
- 성공하면 `task5_handoff/index.html` 생성. 기존 `task3_card_studio` 파일은 읽기만 하며 수정하지 않음.
- 이후 `python -m http.server 8000`을 실행해 `http://localhost:8000/task5_handoff/` 확인.
- 생성 및 브라우저 수동 검증은 **사용자 측 실행 전까지 NOT_RUN**.
- GitHub 커밋/실제 저장소 버전 ID는 업로드 전이므로 **미기록**. 이 항목은 카드 2의 직접 검증 후 실제 커밋 링크와 40자리 SHA를 추가.
